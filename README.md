This mod lets you pick up and re-place lockers and buildables from three categories (Interior Modules, Exterior Modules, Miscellaneous) instantly, preserving the original storage instance so containers keep their inventory and behavior after moving. 

Because, as the song goes, “I like to move it, move it !” — now your lockers do too (underwater edition)

Features:
• Instant pick-up and place for lockers (works even when lockers contain items).
• Support for moving buildables in three categories: Interior Modules, Exterior Modules, Miscellaneous.
• Preserves storage identity and contents after moving.

Usage:
• Aim at a locker or supported buildable with the Habitat Builder and press ALT to enable move mode.
• ALT + Left-click to pick up instantly; move and place to rebuild instantly.
• Cancel returns the object to its original position.

    "ALT + Left-click" to pick up/place with the Habitat Builder


Requirements:
• Subnautica
• BepInEx
• Nautilus (for in-game options; optional but recommended)

Installation:
1. Copy ILikeToMoveIt.dll to <Subnautica folder>\BepInEx\plugins\ILikeToMoveIt\
2. If provided, copy Assets\move.png to <...>\BepInEx\plugins\ILikeToMoveIt\Assets\
3. Start the game. Configure options in Nautilus if available.
